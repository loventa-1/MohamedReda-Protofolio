# Mohammed Reda Portfolio

A responsive personal portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Run

Open `index.html` directly or serve the `portfolio` folder with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Edit the `portfolioData` object at the beginning of `js/script.js`. It controls personal details, links, education, experience, skills, projects, testimonials, and services.
